### What was added in Session 8 — HITL Command Approval + Live Embedded Terminal

**New packages installed:**
- `@xterm/xterm` ^6.0.0 — browser terminal emulator (core)
- `@xterm/addon-fit` — auto-resize xterm to container
- `@xterm/addon-web-links` — clickable URLs in terminal
- `node-pty` — native shell PTY spawning on the server

**New server features:**
- `WebSocketServer.ts` — `pty:spawn`, `pty:input`, `pty:resize`, `pty:kill` message handlers; `handlePtySpawn()` spawns real shell via node-pty; `killPtySession()` cleans up on disconnect; `chat:toTerminal` routes AI-initiated commands to PTY

**New stores:**
- `client/src/lib/stores/commandAllowlistStore.ts` — Zustand+persist store; `requestApproval(cmd, cwd, projectId)` returns a Promise; allowlist entries keyed by normalised executable name; scopes: `once | project | global`

**New components:**
- `client/src/components/terminal/HITLCommandApproval.tsx` — floating approval dialog; reads `pending` from commandAllowlistStore; 4 buttons: Allow Once / Allow for Project / Allow for All Projects / Deny; Escape = Deny; keyboard focus on Deny by default
- `client/src/components/terminal/EmbeddedTerminal.tsx` — full live xterm.js terminal; shell selector (bash/zsh/sh/fish/python3/node); WebSocket connection to `/ws`; HITL gate intercepts Enter keypress before forwarding to PTY; fires `omnecor:terminal_output` CustomEvents for chat bridge

**New LOCAL inputs (+13):**
1. **EmbeddedTerminal — Shell selector dropdown**: changes `shell` state and calls `handleRestart(newShell)` to kill + re-spawn PTY
2. **EmbeddedTerminal — Restart button**: kills existing PTY session + re-spawns with current shell
3. **EmbeddedTerminal — Enter keypress (HITL gate)**: intercepts Enter, runs `requestApproval(cmd, cwd, projectId)`, forwards or blocks to PTY
4. **EmbeddedTerminal — Escape key**: `_resolvePending(null)` → deny current pending approval
5. **EmbeddedTerminal — xterm resize observer**: auto-sends `pty:resize` to keep PTY cols/rows in sync
6. **HITLCommandApproval — "Allow Once" button**: `_resolvePending("once")` — command runs, not saved to allowlist
7. **HITLCommandApproval — "Allow for Project" button**: `_resolvePending("project")` — saves to allowlist scoped to `projectId`
8. **HITLCommandApproval — "Allow for All Projects" button**: `_resolvePending("global")` — saves globally, never asked again
9. **HITLCommandApproval — "Deny" button**: `_resolvePending(null)` — blocks command, prints `[HITL] Command denied.` in terminal
10. **HITLCommandApproval — Escape key handler**: same as Deny button
11. **Chat.tsx — Terminal output → chat bridge**: listens for `omnecor:terminal_output` events, debounces 2 s, injects terminal output as `[system]` message into current conversation
12. **Chat.tsx — `chat:toTerminal` WS messages**: AI-initiated commands routed through HITL approval before execution
13. **commandAllowlistStore — `clearProjectEntries` / `clearAllEntries`**: management actions for the persistent allowlist

**New CONNECTED inputs (+2):**
1. **EmbeddedTerminal — `pty:spawn` WS message**: sends shell + cwd + cols/rows to server → spawns real PTY session
2. **EmbeddedTerminal — `pty:input` / `pty:resize` / `pty:kill` WS messages**: bidirectional real-time PTY I/O
