## About Omnecor

Omnecor is a production-ready context-aware AI infrastructure platform featuring:
- React 19 frontend with Tailwind CSS 4
- Real-time chat interface
- Multi-provider AI support
- Enterprise-grade security

For full documentation, see the main [docs](../) folder.
