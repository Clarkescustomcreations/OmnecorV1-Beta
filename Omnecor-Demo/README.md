# Omnecor - AI Workstation

Complete, production-ready package of Omnecor v2.1.0 - a context-aware AI infrastructure platform.

## What's Included

- Full-stack Node.js application with React frontend
- Built production assets
- Complete source code
- Deployment guides

## Quick Start

### Deploy to Vercel
```bash
cd source/
git push to GitHub
Connect to Vercel
```

### Local Development
```bash
cd source/
pnpm install
pnpm dev
```

## Requirements

- Node.js 22+
- MySQL 8.0+
- OAuth provider

## Technology Stack

- Frontend: React 19, Tailwind CSS 4, TypeScript
- Backend: Node.js, Express, tRPC
- Database: MySQL with Drizzle ORM
